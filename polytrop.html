1.1.5 Polytrope Zustandsänderung

Hier entstehen deine Gleichungen zum variablen Polytropenexponenten (n) für reale, technisch geführte Prozesse.

pVx = konstant
  • x = 0: isobar
  • x = 1: isotherm
  • x = κ: isentrop (adiabatisch reversibel)
  • x  →  unendlich: isochor


Q = nCv ((x-κ)/(x-1)) (T2-T1)
bzw.

Q = n · CV · x − κ x − 1 · ( T2 − T1 )


Polytrope Wärmekapazität:

Cx = CV · x − κ x − 1


Ermittlung Polytropenexponent x:
x = ln (p2/p1) / (ln (p2/p1) - ln (T2/T1))
bzw.

x = ln p2 p1 ln p2 p1 − ln T2 T1


W = (p1V1/(x-1)) [ (V1/V2)(x-1) -1 ]
W = (p1V1/(x-1)) [ (T2/T1) -1 ]
W = (p1V1/(x-1)) [ (p2/p1)((x-1)/x) -1 ]

κ: Isentropenexponent
x: Polytropenexponent
