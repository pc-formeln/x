1.1 Thermodynamische Potentiale

Übersicht und fundamentale Gleichungen der thermodynamischen Zustandsfunktionen.

Klassische Hauptpotentiale

Innere Energie (U)

ΔU = Q + W (+ ∑ µi dNi)
 →  dU = δQ + δW (+ ∑ µi dNi)
U(T,V,N) = T · S + F
U(T,p,N) = T · S - pV + G
U(T,V,µ) = T · S + µN + Ω

(+ ∑ µi dNi) bei Aggregat-/Stoffumwandlung

Enthalpie (H)

H = U + pV

Freie Energie / Helmholtz-Energie (F)

F = U - T · S
 →  dF = (dU - TdS)V,T
 →  dFV,T = δWrev

 →  reversible Nutzarbeit bei isotherm-isochor

Freie Enthalpie / Gibbs-Energie (G)

G = H - T · S = F + pV
dG = (dH - TdS)p,T  →  dGp,T = δWrev

 →  reversible Nutzarbeit bei isotherm-isobar

Erweiterte und teilchenfreie Potentiale

Großkanonisches Potential (Ω)

Ω = F - μN = U - T · S - µN

Potential R (Teilchenfreies Energiepotential)

R = U - μN

Potential J (Teilchenfreies Enthalpiepotential)

J = R + pV

Potential K (Entropisches Hilfspotential)

K = G - μN

Fundamentale Differentialgleichungen in Abhängigkeit von den natürlichen Variablen

dS(U,V,N) = 1/T dU + p/T dV - µ/T dN
dU(S,V,N) = TdS - pdV (+ Σ µi dNi)
dH(S,p,N) = TdS + Vdp (+ Σ µi dNi)
dF(T,V,N) = -SdT - pdV (+ Σ µi dNi)
dG(T,p,N) = -SdT + Vdp (+ Σ µi dNi)
 →  bei p,T=konst. gilt dG = Σ µi dNi = δW
 →  Extraarbeit durch Veränderung der Zusammensetzung des Systems

dΩ(T,V,µ) = -SdT - pdV (- Σ Ni dµi)
dR(S,V,µ) = TdS - pdV (- Σ Ni dµi)
dJ(S,p,µ) = TdS + Vdp (- Σ Ni dµi)
dK(T,p,µ) = -SdT + Vdp (- Σ Ni dµi)

Weitere Berechnungshilfen

ΔS isotherm:    dS = δQ / T

ΔS isobar:    dS = δQ / T = CpdT / T

ΔS isochor:    dS = δQ / T = CvdT / T

ΔU isotherm:    dU = TdS - pdV
                           →  wenn W = -Q dann dU = 0

ΔU isobar:    dU = TdS - pdV = CpdT - pdV

ΔU isochor:    dU = TdS = CvdT

ΔH isotherm:    dH = TdS + pdV = δQ + Vdp
                           →  wenn W = -Q dann dU = TdS - pdV = 0
                           →  dann dH = pdV + Vdp = d(pV)
                           →  wenn pV = konst. dann dH = 0

ΔH isobar:    dH = TdS = CpdT

ΔH isochor:    dH = TdS + Vdp = CvdT + Vdp

ΔF isotherm:    dF = -pdV
                           →  wenn W = -Q dann dU = TdS - pdV = 0
                           →  dann dF = -TdS = -δQ

S:    dS = δQ / T (+ Wdiss / T )
        →  Klammer wenn zusätzliche Reibungsarbeit

V=V(T,p)
dV = (∂V/∂T)pdT + (∂V/∂p)Tdp
dV = VγdT - Vαdp
V(T,p) = V0 (1 + γ (T-T0) - α (p-p0))
α: isothermer Kompressibilitätskoeffizient
γ: isobarer Volumenexpansionskoeffizient

S=S(V,T)
dS = (∂S/∂V)TdV + (∂S/∂T)vdT
(∂S/∂V)T = (∂p/∂T)v = R/V
(∂S/∂T)v = Cv/T
S = S0 + nR ln (V2/V1) + nCv ln (T2/T1)

S=S(p,T)
dS = (∂S/∂p)Tdp + (∂S/∂T)pdT
(∂S/∂p)T = -R/p
(∂S/∂T)p = Cp/T
S = S0 - nR ln (p2/p1) + nCp ln (T2/T1)

S=S(p,V)
dS = (∂S/∂p)vdp + (∂S/∂V)pdV
S = S0 - nCv ln (p2/p1) + nCp ln (V2/V1)
 →  für polytrope Zustandsänderung

S=S(U,V)
dS = dU/T + (p/T)dV
ΔS = ∫ (1/T)dU + R ln V
 →  gilt für ideales Gas; U unabhängig von V!
ΔS = Cv ln U + R ln V

H=H(T,p)
dH = (∂H/∂T)pdT + (∂H/∂p)Tdp
(∂H/∂T)p = Cp
(∂H/∂p)T = V - T(∂V/∂T)p = V(1-Tα)
(∂H/∂p)T = 0; für ideales Gas
(∂H/∂p)T = V0; für inkompressible Flüssigkeiten
inkompressible Flüssigkeit:
 →  Cp=Cv=C(T)
 →  V0 = konst. und unabhängig von p
H = H0 + ∫ C(T)dT + ∫ V0dp
... = H0 + ∫ C(T)dT + V0(p2-p1)

H=H(p)
(∂H/∂p)Tdp << (∂H/∂T)pdT; außer in Geo- oder Astrophysik
... mit hohen Druckänderungen
(∂H/∂p)T = V - T(∂V/∂T)p
(∂H/∂p)T ≈ V; für Flüssigkeit und Festkörper
 →  dH ≈ CpdT + Vdp
(∂H/∂p)T = 0; für ideales Gas

H=H(T)
ΔRH = HProdukt - HEdukt
ΔRH(T2) = ΔRH(T1) + ∫ (CpProdukt - CpEdukt) dT

Einheitenreferenz

J (Joule): SI-Einheit für Energie, Arbeit und thermische Potentiale.

K (Kelvin): SI-Einheit für die absolute thermodynamische Temperatur.
