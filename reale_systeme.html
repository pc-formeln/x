1.2 Gastheorie, Reale Systeme, Festkörper

Energie, Wärmekapazität und Freiheitsgrade idealer Gase

U = (f/2)nRT;
ΔU = (f/2)nR ΔT

Cp = Cv + nR

Cv = nRf/2

κ = Cp / Cv = 1 + (2/f)

In einem bestimmten Temperaturfenster (meist rund um Raumtemperatur) gilt:
  • 1-atomiges Gas: κ = 5/3 = 1,67; bei f = 3
  • 2-atomiges Gas: κ = 7/5 = 1,40 ; bei f = 5
  • 3-atomiges Gas: κ = 8/6 = 1,33 ; bei f = 6

  • 1-atomiges Gas: 3x Translation
  • 2-atomiges Gas: 3x Translation + 2x Rotation
  • 3-atomiges Gas linear: 3x Translation + 2x Rotation
  • 3-atomiges Gas nicht linear: 3x Translation + 3x Rotation
  • Rund um Raumtemperatur (25 °C) sind Schwingungen (Oszillationen) bei fast allen kleinen Molekülen (außer sehr schweren wie I2) noch vollständig eingefroren.
f: Freiheitsgrade
κ: Adiabaten-/ oder Isentropenexponent

Regel von Dulong und Petit

Cv,m ≈ Cp,m ≈ 3R ≈ 25 J mol-1 K-1
  • gilt nur für hohe Temperaturen
  • 3x kinetische + 3x potentielle Schwingungsenergie
  • f = 6

f: Schwingungs Freiheitsgrade

Joule - Thomson - Koeffizient

µJT = (∂T / ∂p)H

ideales Gas: µJT = 0
reales Gas: µJT = (2a/(RT) - b) / Cp

dH = 0
0 = CpdT + (∂H / ∂p)T dp
0 = Cp (∂T / ∂p)H + (∂H / ∂p)T
µJT = (-1/Cp) (∂H / ∂p)T

(∂H / ∂p)T schwer meßbar deshalb = V - T (∂V / ∂T)p
µJT = (1/Cp) [ T (∂V / ∂T)p - V ]

ΔU = W1 + W2
U2 - U1 = p1V1 - p2V2; bei realen Gasen ΔU<>0
H2 = H1; isenthalp

Tinv = 2a / (Rb)

Van-der-Waals-Isothermen und Maxwell-Konstruktion im p-V-Diagramm

Das Phänomen der unphysikalischen Schlaufen:
Für Temperaturen unterhalb der kritischen Temperatur (T < Tkrit) liefert die rein mathematische Lösung der kubischen Van-der-Waals-Gleichung einen S-förmigen Kurvenverlauf (Schlaufe). In einem Teilbereich besitzt diese Welle eine positive Steigung (∂p/∂V > 0), was mechanisch instabil und physikalisch unmöglich ist.
Die Maxwell-Konstruktion (Gleichflächenmethode):
Da im realen System bei der Kompression an diesem Punkt die Verflüssigung einsetzt, bricht die Isotherme horizontal ab. Der unphysikalische Schaufeleffekt wird durch eine waagerechte Verbindungslinie (Maxwell-Gerade) ersetzt, welche die Schlaufe so schneidet, dass die eingeschlossenen Flächen oberhalb und unterhalb der Geraden exakt gleich groß sind. Sie markiert den konstanten Kondensationsdruck im Nassdampfgebiet, in dem Flüssigkeit und Gas stabil koexistieren.
a: Binnendruck
b: Kovolumen

Barometrische Höhenformel

p(h) = p0 · e−(M · g · h) / (R · T)
ln(p / p0) = −(M · g / (R · T)) · h

Dabei steht M für die mittlere molare Masse des Gases. Für trockene Luft gilt der thermodynamische Richtwert:
M(Luft) ≈ 29 g/mol (bzw. 0,029 kg/mol für SI-Einheiten).
