Berechnung der Absoluten Entropie (Dritter Hauptsatz):
Nach dem Nernst'schen Wärmesatz geht die Entropie ideal kristallisierter, reiner Stoffe am absoluten Nullpunkt gegen Null (S = 0 bei T = 0 K). Die absolute Entropie bei einer Zieltemperatur T ergibt sich durch die Summation der Erwärmungsentropien der einzelnen Phasen und der Phasenumwandlungsentropien:

S(T) = ∫0Tm ( Cp,fest / T ) dT + ΔHfus / Tm + ∫TmTb ( Cp,flüssig / T ) dT + ΔHvap / Tb + ∫TbT ( Cp,gas / T ) dT
• Tm / Tb: Schmelztemperatur (melting) und Siedetemperature (boiling).
• ΔHfus / ΔHvap: Molare Schmelzenthalpie und molare Verdampfenthalpie.
• Cp / T: Die Integrale entsprechen den Flächen unter den Kurven im Diagramm, wenn Cp/T gegen T aufgetragen wird (bzw. direkt ∫ Cp d(ln T)).
