1.1.4 Adiabatische Zustandsänderung

Hier entstehen deine Beziehungen zu den Adiabatenexponenten (κ) und isentropen Systemänderungen.

δQ = 0

pVκ    =konst.
TVκ-1 =konst.
Tκp1-κ=konst.

isentropisch wenn reversibel

p1V1κ = p2V2κ

T1/T2 = (V2/V1)κ-1

T1/T2 = (p1/p2)(κ-1)/κ

nCp dln T = nR dln p; gilt wenn reversibel, sonst nicht!

W = ΔU

ΔH = nCpΔT

ΔU = nCvΔT

dU = δW = -pdV

W = ΔU = nCvΔT (rev. + irrev.)

W = (p2V2 – p1V1) / (κ-1)

Wirr = -p2 (V2-V1) ; V2 = nRT2 / p2 ; irreversibel

ΔS = 0; reversibel

dU = δW
CV dT = - pdV
p=nRT/V  →  CV dT/T = -nR dV/V
Cv ln (T2 / T1) = -nR ln (V2 / V1)
ln (T2 / T1)-c = ln (V2 / V1) mit c = Cv / nR
V2T2c = V1T1c

T2 − T1 = T1 · ( V1 V2 c − 1 )
